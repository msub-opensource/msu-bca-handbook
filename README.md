### ⚠️ Public Repo Reality Check (Please Read!)
1. **This is a public GitHub repository**: That means literally anyone with an internet connection — including our professors, lab assistants, and that one overachiever in class — can see this.
2. **DO NOT blindly copy-paste**: If 15 people submit the exact same script with the exact same variable names, typos, and formatting, you are all getting cooked together in the viva. 💀
3. **How to use this safely**:
   - Understand how the code/document works (check the `README.md` guide inside each assignment folder).
   - Change variable names, comments, and structure.
   - Run the code yourself before submitting.

> **"It worked on my machine"** is not a valid answer when your professor is standing in front of you.
