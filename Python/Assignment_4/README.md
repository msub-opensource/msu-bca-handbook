## 💡 Quick Note

- `while` loops are useful when you need to repeat something until a condition changes (e.g., waiting for specific user input).
- `for` loops with `range(start, stop, step)` are best when you know in advance how many times to loop. Remember that `range(1, 11)` stops at `10`! 🎯
